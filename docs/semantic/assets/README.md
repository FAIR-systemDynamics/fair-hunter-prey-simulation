Both were obtained from the official [NFDI4Ing Jupyter service](https://jupyter.nfdi4ing.de/)
on 2026-10-08 and are reproduced without alteration:

- `nfdi4ing-logo.png`: <https://jupyter.nfdi4ing.de/assets/g222.png>
- `jupyter-logo.svg`: the inline SVG linking to `https://jupyter.org/` on that page.
